# Tourismia.AE screenshots

Captured from the user's own running Tourismia.AE concept on 17 October 2026 with headless Chromium. Screenshots show the actual interface, including the tour panel; no mockups or replacement images were generated.

All four views are 1280 × 799 pixels, converted from PNG to WebP at quality 92. Each view was captured after its entrance animation completed.

- home.webp: Homepage with the skyline photograph and destination, experience and budget search.
- catalogue.webp: Category filters, sorting and the first row of tour cards.
- tour.webp: Sunset desert safari panel with key details and included items.
- enquiry.webp: Meeting point notes, enquiry form and estimated total.

This is portfolio concept work. Its development address is not part of the public project record, and no live deployment link is displayed.
