# Floria screenshots

Captured from the user's own running Floria concept. Screenshots show the actual interface, including the arrangement dialog; no mockups or replacement images were generated.

Files are WebP at quality 92, at native capture width (2000 px).

- home.webp (2000 × 1209): Homepage with flower photography and palette choices.
- collection.webp (2000 × 1075): Three arrangements with prices and flower varieties.
- arrangement.webp (2000 × 1084): Arrangement details, size choices, optional gift note and bag action.
- approach.webp: Florist photograph with composition and care information. Not referenced by `src/data/projects.ts`.

This is portfolio concept work. Its development address is not part of the public project record, and no live deployment link is displayed.
