# Floria screenshots

Captured from the user's own running Floria concept on 17 October 2026 with the collaborative browser. Screenshots show the actual interface, including the arrangement dialog; no mockups or replacement images were generated.

All four views are 1280 × 799 pixels, converted from PNG to WebP at quality 92. The approach view was captured after its entrance animation completed.

- home.webp: Homepage with flower photography and palette choices.
- collection.webp: Three arrangements with prices and flower varieties.
- arrangement.webp: Arrangement details, size choices, optional gift note and bag action.
- approach.webp: Florist photograph with composition and care information.

This is portfolio concept work. Its development address is not part of the public project record, and no live deployment link is displayed.
